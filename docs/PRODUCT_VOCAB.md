# 拾词 · 完整产品稿

## 一句话定位

拾词不是“每天必须背多少个词”的打卡工具，而是一间私人英文阅读与听读室：用户从真正想读的文章、想听的播客里理解词语，把它和当时的语境一起留下，再在合适的时候回到这段语境。

## 产品原则

1. **语境先于词表。** 解释必须知道目标词、当前句和相邻语境；复习优先回到原句，不把词拆成孤立的中英对照。
2. **英文先于中文。** 第一次解释默认用清晰英文；中文是用户主动展开的理解辅助，不是强制答案。
3. **一次动作就有反馈。** 点击词或短语后立即开始解释，不要求再点一次“用 AI 解释”；仍允许在离线时只保存语境。
4. **没有证据就不统计。** 不播种虚构的阅读时长、复习次数、进度或连续天数；只展示真实发生的记录。
5. **没有欠账。** “现在可复习”只是一个可选入口，不是红点催促；删除 streak、隐藏目标环、断签和完成率。
6. **本地不等于永不丢。** SQLite 和 OPFS 属于当前浏览器 origin；界面说明持久化状态、备份范围和站点数据清理风险。
7. **所有外发都由用户触发。** URL/RSS/AI/转写/远程音频均有清楚边界；本地锁开启后不能发生任何这些请求。
8. **按钮只承诺真实动作。** “搜索”必须搜索，“返回”必须回资料库，“完整备份”必须包含本地音频，“检查连接”必须做真实请求。

## 信息架构

- 今日：最近正在读/听的内容、现在可复习、最近保存的词。没有目标环和 streak。
- 资料库：文章、播客、归档；支持全文元数据搜索和明确的“移入归档 / 恢复”。
- 阅读：文章正文、当前位置、书签、点词解释。
- 收听：真实音频、播放位置、倍速、字幕、点词解释；无时间轴文本明确标“未对齐”。
- 词库：词、英文解释、原语境、状态、笔记、收藏。
- 复习：到期旧卡优先，再加入不超过本地当日上限的新卡；所有评分预告与实际调度一致。
- 数据：最近 7 天真实发生的阅读/收听/复习，描述节奏，不评价自律。
- 设置：阅读体验、AI/隐私、本地持久化、复习节奏、完整备份。
- 全局搜索：`⌘/Ctrl K` 搜索资料、词和原语境，并直接打开真实目的地。

## 核心流程

### 1. 导入文章

支持：

- 网页 URL：用户点击导入后，由安全代理提取标题、作者、来源和正文。
- 粘贴文本：完全本地解析。
- TXT / Markdown / HTML：完全本地解析，移除脚本、样式、表单、iframe、SVG 等不可读或危险内容。

保存前展示可编辑草稿：标题、作者、来源、正文块数量和开头预览。空正文、超限文件和异常结构不写库。重复 URL 或相同正文 hash 只提醒，不擅自合并。

### 2. 导入播客

支持：

- RSS：先读取节目目录，再由用户选择单集；列表必须说明“显示 20/总数”或提供加载更多。
- 本地音频：流式写入 OPFS，SQLite 只保留受控媒体资产引用。
- VTT / SRT / LRC：保留真实时间轴。
- 纯文本字幕：保存为“未对齐文本”，不生成伪造的 5 秒时间码，不自动跟随。
- 外部转写：仅在服务确实已配置、用户明确勾选且没有可用字幕时上传；选择了有效字幕后自动禁用转写。

导入 RSS 单集时保留真实发布日期、feed 名称、原页面和音频 URL。导入失败不留下半条项目或孤儿 OPFS 文件。

### 3. 阅读与真实进度

- 文章滚动进度按最靠上的可见 block 保存，节流写入；再次打开回到附近位置。
- 只在页面可见且用户最近有滚动/选择/键盘活动时累计阅读秒数；后台静置不计。
- 书签记录当前可见 block，可回看、跳转、加注和删除；同一 locator 幂等。
- “标记为读完”是可逆状态，不把阅读变成任务完成率。

### 4. 收听与真实进度

- metadata 就绪后把真实 `<audio>.currentTime` 恢复到保存位置，不只移动界面滑块。
- 暂停、退出、页面隐藏和定时节流时保存播放进度。
- 仅在 `playing` 且页面可见时累计收听秒数。
- 本地锁开启时，只允许 `local:` 媒体；远程播客显示“本地锁阻止了远程音频，可继续阅读字幕”。
- 无音频时字幕仍可读、可选词，不显示可点击但无效的播放按钮。

### 5. 点词与 AI 解释

一次点击或短语选择后立即：

1. 打开具名语境面板并把焦点移入。
2. 展示目标词与将要发送的当前句。
3. 若本地锁关闭，自动发起英文解释；若关闭则保留本地语境并说明。
4. 通过 request ID + AbortController 将结果绑定到完整 selection identity；切词、关闭、切页时取消，迟到响应绝不能覆盖新词。
5. 严格解析字段类型、长度和数组上限；错 schema 只显示错误，不写入词库。
6. 中文解释按需另发请求，并同样绑定当前 selection。

文章上下文取当前句及相邻句；播客上下文除当前字幕段外，还传前一段和后一段。保存时 explanation 必须与 selection identity 匹配。

允许离线保存词和语境，但没有有效英文答案的复习卡保持 suspended，不进入队列。联网补齐解释后再由用户选择加入学习。

### 6. 词库

词条展示：词头、发音、当前语境英文义、出现来源、状态和个人笔记。一个词可拥有多个 occurrence；不让后来语境静默覆盖旧语境，而是保留每次解释 JSON 和时间。

状态：

- 已保存：留在词库，未必进入复习。
- 学习中：进入 SRS。
- 已掌握：暂停复习卡，可随时恢复。
- 已忽略：暂停且从默认列表隐藏。

收藏只影响筛选，不等于学习状态。

### 7. SRS v2

- 队列顺序：到期 learning/review/relearning → 当地今日未引入且不超过 `daily_new_limit` 的 new。
- 上限只限制新卡，不隐藏已经到期的旧卡。
- 调度逻辑抽成纯函数；UI 的“10 分钟 / 6 天”等预告直接读取同一函数结果。
- cloze 不用未转义词头构造正则；`C++`、`[sic]` 和短语均能安全显示。
- 评分事件保存 before/after、算法版本和 activity event id。
- 撤销只允许最近一个未撤销评分，并在同一事务中恢复卡片、事件和统计。
- 当地日期使用 `Intl`/本地年月日，不用 UTC slice；新加坡 00:30 必须属于当天。

评分文案保持中性：

- 再看一次
- 有点难
- 记得
- 很熟

不使用“失败”“错误率”“欠卡”。复习完成只说“这一轮到这里”，不制造必须清零的义务。

### 8. 统计与心理体验

保留能支持决定的事实：

- 最近 7 天有记录的阅读/收听分钟。
- 回到语境的次数。
- 文章与播客比例。
- 已保存 / 学习中 / 已掌握分布。

删除：

- 连续学习天数。
- 隐藏的 18 分钟目标环。
- 红色待复习 badge。
- 完成率、正确率和每日目标达成。

零数据页面仍然成立：“还没有学习记录。读一点、听一点，记录会在这里自然出现。”

## 数据与存储

### Runtime schema v1

继续以当前 `vocab_*` 表为真实 legacy 基础，不切换到未运行的 reference schema。首次迁移：

- 识别精确 legacy 表集合。
- 事务内设置 `application_id = SHICI` 与 `user_version = 1`。
- 建立 migration ledger。
- 所有 DML 改为显式列名。
- 空库不再插入个人 activity、review event、进度或词条；如保留 starter 内容，必须是清楚标注且不计入个人数据的只读模板。

新增媒体资产表，至少包含：storage kind、OPFS key / remote URL、原名、MIME、byte size、SHA-256、状态和时间。禁止继续用 `local:` 字符串同时承担类型和引用。

### 跨标签页

所有 Vocab 读写、文件写入、导出和恢复参与同一个 Web Lock；generation 激活通过 BroadcastChannel 让其它标签页重载。普通写不能绕过锁。

### 完整备份

`.vocab-backup` 容器包含：

- 版本化 manifest 与自身 SHA-256。
- 带 application id / user version 的 SQLite。
- 数据库真实引用的全部 OPFS 音频及元数据。
- 每段 byte size、SHA-256、导出时间和引用关系。

导出前反查所有本地媒体引用；缺文件、同尺寸篡改或 metadata 不一致时整体失败，不生成“完整备份”。API key、模型日志和临时请求绝不进入文件。

恢复复用 immutable generation + READY + checksum A/B pointer：先完整解析和 hash，写随机附件候选，stage 数据库，迁移并校验表列/identity/FK/引用集合，再激活。任何失败只能保持全旧或得到全新，不能 hybrid。旧 SQLite 走同一 candidate 路径，并清除无法恢复的本地媒体引用。

## 隐私与网络

- `.env.local` 只在服务端读取，不进入 bundle、SQLite 或备份。
- AI 请求只包含目标、当前句和相邻语境；面板展示这个边界。
- 本地锁是强制网络边界，不是文案开关。
- URL/RSS/媒体代理继续限制协议、重定向、大小、超时；媒体流按实际累计字节中止，不能只信 Content-Length。
- 转写设置状态来自 `/api/health.transcription.configured`；未配置时禁用，不能让用户等待后才得到 503。
- 上游 429/401/5xx 保留可理解语义；不把 429 一律伪装为 502。

## Apple UI 与无障碍

- 使用系统字体、克制色彩、清晰层级和足够留白；不靠过大的装饰衬线字制造“高级”。
- 主标题、正文、辅助文字建立统一字阶；正文最小 16px，功能说明满足 4.5:1。
- 所有移动触控目标至少 44px，safe-area 不遮挡。
- ContextPanel、WordDetail、ImportWizard、全局搜索和移动侧栏都作为具名 dialog：初始焦点、Tab 圈定、背景 inert、Escape、滚动锁和焦点归还完整。
- 文章点词必须有键盘等价入口：全局搜索或“解释一个词/短语”动作可直接输入并附带当前段落。
- 字幕当前段不只用颜色表达；播放器按钮有“播放/暂停”“收藏当前时间”等准确名称。
- reduced-motion 关闭自动 smooth scroll 与所有装饰动画。

## 发布验收

1. 全新 profile 打开：所有个人统计为 0，无虚构到期卡；starter 内容若存在必须清楚标注且不写进统计。
2. 文章滚动、书签、退出/刷新后恢复；后台停留不累计。
3. 本地音频播放、暂停、倍速、恢复位置、真实收听秒数；远程音频在本地锁下 0 请求。
4. 点 A 后立即点 B，A 迟到结果不能出现在 B；异常 AI schema 不入库。
5. 有字幕 + 勾过转写时 0 次上传；未配置转写入口提前说明。
6. daily limit、四种评分、known/ignored、当地午夜、撤销统计和特殊字符 cloze 全部有固定时钟测试。
7. 完整备份含 0/1/多音频 round-trip；损坏 manifest/DB/任一音频不切换 active generation。
8. 319×734 与桌面：无横向溢出；所有 dialog 焦点与关闭归还正确；键盘可完成导入、搜索、选词替代入口和复习。
9. 全量 lint、typecheck、测试、五环境 production build 通过；服务重启与浏览器重启后 SQLite/OPFS 均可用。
